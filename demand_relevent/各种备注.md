# 1备注：
CAIS用的是虚拟环境，安装包的时候要安装到虚拟环境里：

激活虚拟环境：

source /Users/huihang/Desktop/CAIS/.venv/bin/activate


然后在虚拟环境里安装：

pip install requests


确认安装：

python -m pip show requests
