## 第五步：深度分析

### 方式1：用Python脚本分析

创建 `analyze_results.py`：

```python
#!/usr/bin/env python3
import json
import statistics

# 加载结果
with open('pause_test_report.json', 'r') as f:
    report = json.load(f)

print("\n=== 深度分析 ===\n")

# 按维度统计
by_dimension = {}
for result in report['results']:
    dim = result['dimension']
    if dim not in by_dimension:
        by_dimension[dim] = []
    by_dimension[dim].append(result)

for dimension, results in by_dimension.items():
    pause_stats = [r['stats']['pause_mean_ms'] for r in results]
    resume_stats = [r['stats']['resume_mean_ms'] for r in results]
    
    print(f"【{dimension}】")
    print(f"  暂停耗时平均: {statistics.mean(pause_stats):.2f}ms")
    print(f"  暂停耗时范围: {min(pause_stats):.2f} - {max(pause_stats):.2f}ms")
    print(f"  暂停耗时标准差: {statistics.stdev(pause_stats) if len(pause_stats) > 1 else 0:.2f}ms")
    print(f"  恢复耗时平均: {statistics.mean(resume_stats):.2f}ms")
    print(f"  恢复耗时范围: {min(resume_stats):.2f} - {max(resume_stats):.2f}ms")
    print(f"  恢复耗时标准差: {statistics.stdev(resume_stats) if len(resume_stats) > 1 else 0:.2f}ms")
    print()

# 查找异常
print("【异常检测】")
for result in report['results']:
    if result['errors']:
        print(f"⚠️  {result['description']}: {result['errors']}")
    
    pause_max = result['stats']['pause_max_ms']
    pause_avg = result['stats']['pause_mean_ms']
    if pause_max > pause_avg * 1.5:
        print(f"⚠️  {result['description']}: 暂停波动较大 "
              f"(平均{pause_avg:.2f}ms, 最大{pause_max:.2f}ms)")
```

运行：
```bash
python analyze_results.py
```

## 常见问题

### Q: 测试会花多长时间？

**A:** 计算公式：
```
总时间 ≈ 测试用例数 × 重复次数 × (文件行数 / 速度 + 10秒间隔)

示例：
- 12个测试用例
- 每个重复3次
- 每个文件5000行，速度~50行/秒 = ~100秒
- 总估计: 12 × 3 × (100 + 10) = 3960秒 ≈ 1小时
```

### Q: 测试中断了怎么办？

**A:** 
```bash
# 查看已生成的部分结果
cat pause_test_report.json

# 从上次中断的地方继续
# 修改 run_tests.py，只测试剩下的用例
python run_tests.py
```

### Q: 想要保存多次测试的结果？

**A:**
```bash
# 每次测试前重命名结果文件
mv pause_test_report.json pause_test_report_run1.json
mv pause_test_results.csv pause_test_results_run1.csv

# 运行新测试
python run_tests.py

# 现在有两套结果可以对比
```

### Q: 能否只测试其中某些用例？

**A:** 修改 `run_tests.py` 中的用例生成代码：

```python
testcases = []

# 只测试维度1

    'test_files/medium_test.gcode',

# 注释掉维度2和3
# testcases += tester.generate_dimension2_testcases(...)
# testcases += tester.generate_dimension3_testcases(...)
```

### 生成HTML报告（可选）：

创建 `generate_html_report.py`：

```python
#!/usr/bin/env python3
import json
import statistics

with open('pause_test_report.json', 'r') as f:
    report = json.load(f)

html = """
<html>
<head>
    <title>G-code暂停性能测试报告</title>
    <style>
        body { font-family: Arial; margin: 20px; }
        table { border-collapse: collapse; width: 100%; }
        th, td { border: 1px solid black; padding: 10px; text-align: left; }
        th { background-color: #4CAF50; color: white; }
    </style>
</head>
<body>
    <h1>G-code暂停性能测试报告</h1>
    <p>生成时间: {}</p>
    <table>
        <tr>
            <th>维度</th>
            <th>描述</th>
            <th>暂停耗时(ms)</th>
            <th>恢复耗时(ms)</th>
            <th>总耗时(ms)</th>
            <th>错误</th>
        </tr>
""".format(report['timestamp'])

for result in report['results']:
    html += f"""
        <tr>
            <td>{result['dimension']}</td>
            <td>{result['description']}</td>
            <td>{result['stats']['pause_mean_ms']:.2f} ± {result['stats']['pause_stdev_ms']:.2f}</td>
            <td>{result['stats']['resume_mean_ms']:.2f} ± {result['stats']['resume_stdev_ms']:.2f}</td>
            <td>{result['stats']['total_mean_ms']:.2f}</td>
            <td>{', '.join(result['errors']) if result['errors'] else 'None'}</td>
        </tr>
    """

html += """
    </table>
</body>
</html>
"""

with open('pause_test_report.html', 'w') as f:
    f.write(html)

print("✓ HTML报告已生成: pause_test_report.html")
```
