安装步骤

创建包目录

bashcd ~/catkin_ws/src
mkdir -p gcode_sender/{scripts,msg,srv,launch,config,test}

复制所有文件到对应目录

将上述文件内容保存到对应位置
确保 scripts/gcode_sender_node.py 有执行权限


编译包

bashcd ~/catkin_ws
catkin_make
# 或使用 catkin build
catkin build gcode_sender

配置API Key

编辑 config/gcode_sender_params.yaml
或在launch文件中设置 api_key 参数



启动节点
方法1: 使用launch文件
bashroslaunch gcode_sender gcode_sender.launch api_key:=YOUR_API_KEY
方法2: 使用参数文件
bashrosparam load $(rospack find gcode_sender)/config/gcode_sender_params.yaml
rosrun gcode_sender gcode_sender_node.py
使用示例
命令行调用服务
bash# 开始打印
rosservice call /gcode_sender/start_print "file_path: '/path/to/file.gcode'"

# 暂停打印
rosservice call /gcode_sender/pause_print

# 恢复打印
rosservice call /gcode_sender/resume_print

# 停止打印
rosservice call /gcode_sender/stop_print

# 设置速度
rosservice call /gcode_sender/set_speed "multiplier: 1.5"

# 获取状态
rosservice call /gcode_sender/get_status
订阅话题
bash# 监听进度
rostopic echo /gcode_sender/print_progress

# 监听温度
rostopic echo /gcode_sender/temperatures

# 监听状态
rostopic echo /gcode_sender/state
Python客户端示例
python#!/usr/bin/env python3
import rospy
from gcode_sender.srv import StartPrint, PausePrint

rospy.init_node('my_client')

# 开始打印
start_print = rospy.ServiceProxy('/gcode_sender/start_print', StartPrint)
response = start_print('/path/to/file.gcode')
print(f"Start result: {response.success}")

# 暂停打印
rospy.sleep(10)
pause_print = rospy.ServiceProxy('/gcode_sender/pause_print', PausePrint)
response = pause_print()
print(f"Pause result: {response.success}")

🔍 故障排查
常见问题

无法连接到OctoPrint

检查URL和API Key是否正确
确认网络连接
查看日志: roslog show gcode_sender


服务调用失败

确认节点正在运行: rosnode list
检查服务是否可用: rosservice list | grep gcode_sender


消息未发布

检查话题: rostopic list | grep gcode_sender
查看话题信息: rostopic info /gcode_sender/print_progress



调试命令
bash# 查看节点信息
rosnode info /gcode_sender

rostopic list

rosservice list

roslog tail /gcode_sender
