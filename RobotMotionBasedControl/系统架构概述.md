Stage 6 系统架构概述
三大核心模块

robot_speed_controller.py - 速度监控和控制模块

订阅 ROS 话题获取机器人速度
根据 0.4 m/s 阈值自动控制打印暂停/恢复
记录所有事件到 CSV 日志


stage6_integrated_main.py - 集成主脚本

统一的命令行交互界面
无需修改原 gcode_sender.py 文件
管理打印和速度控制的生命周期


CSV 数据日志

时间戳、机器人速度、触发事件、打印机状态、响应延迟
便于后续分析和优化



关键特性
特性说明 速度源灵活支持 /odom 和 /cmd_vel🔄 防抖机制防止频繁触发，稳定性好📊 数据记录完整的事件日志供分析⏱️ 响应延迟测量记录暂停/恢复的响应时间🧹 无侵入式完全不改动原 gcode_sender.py
工作流程
启动 → 加载打印机控制器 → 订阅机器人速度
  ↓
开始打印 G-code 文件
  ↓
并行运行速度监控线程（200ms 周期）
  ↓
┌──────────────────────────┐
│ 速度 > 0.4 m/s           │
│ ↓ 暂停打印 + 记录事件      │
├──────────────────────────┤
│ 速度 ≤ 0.4 m/s           │
│ ↓ 恢复打印 + 记录事件      │
└──────────────────────────┘
快速启动步骤
bash# 1. 在 ROS 环境中运行
source /opt/ros/humble/setup.bash

# 2. 启动程序
python3 stage6_integrated_main.py

# 3. 在交互界面中执行
>>> print /path/to/file.gcode
# 自动启用速度控制

>>> status
# 查看实时状态

>>> threshold 0.5
# 调整触发阈值
